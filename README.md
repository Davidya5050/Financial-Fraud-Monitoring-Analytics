## 📈 How to Use It

### 1. Review the summary view
Open the dashboard first. Use it to see top-level risk values, flagged transactions, and current trends.

### 2. Filter the data
Use filters to narrow the view by:
- date
- account
- region
- amount
- transaction type
- risk level

### 3. Check for unusual patterns
Look for:
- large payments outside normal ranges
- repeated transactions in a short time
- activity from new locations
- sudden spikes in volume
- records marked with high risk

### 4. Drill into details
Open the transaction sheet to inspect the records behind each chart. This helps you verify whether a case needs review.

### 5. Refresh the dashboard
If you add new records, refresh the workbook so charts, tables, and risk counts update.

## 🖥️ Troubleshooting

### The file does not open
- Make sure the download finished
- Check that Excel is installed
- Try opening the file from the extracted folder

### Excel blocks the workbook
- Right-click the file and check file properties
- If Windows marks it as blocked, allow the file and try again
- Open it again in Excel and enable editing if prompted

### The dashboard does not update
- Check that your data table still uses the same column names
- Save the file before refreshing
- Make sure macros are enabled if the workbook uses them

### Charts look empty
- Confirm that the transaction table contains data
- Check your filters
- Make sure the selected date range includes records
